LIVE APPLICATION
----------------
Main dashboard:
https://casezero-mvp.raknair.workers.dev/dashboard

The main dashboard now includes a clickable Client Readiness overview box with
high-level information on the six use cases, 16/16 live test health, and Azure
telemetry. It links directly to the Demo Guide, Test Status, and Telemetry pages.
All seven navigation items and the Detect, Diagnose, Decide, Act, and Verify
stage counters open their destination in separate browser tabs.
Each of the six incident case cards also opens its case detail in a distinct tab.
Telemetry, Evidence, Policies, Workflows, and Demo Guide drill-down links also
open directly in separate tabs.

Live test dashboard:
https://casezero-mvp.raknair.workers.dev/status

The Test Status page runs all tests directly against the deployed website:
- 9 case-workflow simulation tests
- 7 live API integration smoke tests
- 16 total checks

The current verified result is 16 / 16 checks passed. Use the "Run all tests"
button on the page to rerun the complete suite. Temporary smoke-test cases are
removed automatically after each run.
