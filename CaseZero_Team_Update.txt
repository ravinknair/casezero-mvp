----------------------------------------------------------
WHAT CHANGED
----------------------------------------------------------

Hosting
  - Deployed to Cloudflare Workers (permanent, always on)
  - Replaced ngrok tunnel with a real production deployment
  - All 6 sections now live and working

Application
  - All sections wired up: telemetry, evidence, policies,
    workflows, case detail, dashboard
  - API routes migrated to mock data (no database required)
  - Full approval, rejection, and rollback workflow working

Automation
  - GitHub Actions CI runs on every push:
      lint → test → build
  - Makefile commands for local use:
      make dev       start local server
      make test      run tests
      make build     build for production
      make deploy    build and push to Cloudflare
  - Shell scripts for clean restarts:
      ./start.sh     start the app
      ./stop.sh      stop the app
      ./restart.sh   restart cleanly

Code quality
  - Lint, tests and build all passing
  - README updated with portfolio pitch and how-it-works
  - MIT License added
  - .gitignore configured for Node/Next/Cloudflare projects

----------------------------------------------------------
TO RUN LOCALLY
----------------------------------------------------------

Requirements: Node.js 22+ (install via nvm)

  cd /path/to/casezero-mvp
  npm install
  npm run dev
  open http://localhost:3000
