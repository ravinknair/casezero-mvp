## 🔗 FINDING GITHUB USERNAMES

If they're unsure of their GitHub username, they can:
1. Go to https://github.com/login
2. Log in to their GitHub account
3. Click their profile icon (top right)
4. Click "Your profile"
5. Their username is in the URL: github.com/USERNAME

OR

- Visit their GitHub profile directly: https://github.com/[username]
