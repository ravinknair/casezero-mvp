## 🆘 IF ANYTHING GOES WRONG

**"Tests fail locally"**
```bash
git pull origin main
rm -rf node_modules .next
npm install
npm run test
```

**"Port 3000 is in use"**
```bash
./stop.sh
npm run dev
```

**"Node version mismatch"**
```bash
nvm install 22.13.0
nvm use 22.13.0
```

**"ngrok connection refused"**
- Make sure dev server is running: `npm run dev`
- Make sure ngrok auth token is set: `ngrok config add-authtoken TOKEN`
- Check ngrok dashboard: http://localhost:4040

**"GitHub invitation not received"**
- Check spam folder
- Go to https://github.com/notifications to see pending invites
- Ask them to check their GitHub email preferences
