# How to Add Collaborators on GitHub - Step by Step

If you don't see "Add people", follow these exact steps:

## Option 1: Direct Link (Easiest)

Copy and paste this exact URL into your browser:

```
https://github.com/ravinknair/casezero-mvp/settings/access/collaborators
```

This takes you directly to the Collaborators settings page.

---

## Option 2: Manual Navigation

1. Go to your repository: https://github.com/ravinknair/casezero-mvp

2. Click the **"Settings"** tab (top menu bar)

3. In the left sidebar, click **"Collaborators"** 
   (It's under "Access" section)

4. Click the green **"Add people"** button

---

## What You Should See

Once you're on the Collaborators page, you should see:
- A green button that says "Add people"
- A list of current collaborators (if any)

---

## If You Still Don't See "Add people":

1. Make sure you're logged in to GitHub
2. Make sure you're the repository OWNER
3. Try using the direct link: 
   https://github.com/ravinknair/casezero-mvp/settings/access/collaborators

---

## Next Steps Once You Find "Add people":

1. Click "Add people"
2. Type the first GitHub username: `mrpophali` (or whatever their actual username is)
3. Select their name from the dropdown
4. Choose permission level: **"Push"**
5. Click "Add to repository"
6. Repeat for the second person

---

**Still having trouble?** Make sure:
- You're logged into GitHub
- You own the repository
- You're on the settings/access/collaborators page
